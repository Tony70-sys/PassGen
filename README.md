# PassGen

PassGen is a Python-based password generator with a Tkinter graphical user interface. It allows users to choose a password length and select the types of characters they want to include, such as uppercase letters, lowercase letters, numbers, and special characters.

The project separates the GUI from the password-generation logic to keep the code organized and maintainable.
